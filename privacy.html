プライバシーポリシー

Personal Workflow Automation（以下「本アプリ」）は、個人開発者 Kazuki Akai が運営し、所有者本人だけが利用する個人用の自動化アプリ群です。

取得・利用する情報

本アプリは、所有者が有効にした機能を実行するため、次のGoogleユーザーデータを利用します。

ポートフォリオ月次レポート

  • 所有者が指定したDrive上の保有銘柄・時価総額データを読み取ります。
  • 月次の入力データ、統合データおよびHTMLレポートを、指定されたDriveフォルダに作成・更新します。
  • Google Apps Scriptが生成済みレポートをDriveから読み取り、所有者本人だけが利用できるWebアプリに表示します。
  • レポートのリンクまたは処理失敗の情報を、所有者が指定した宛先へGmail APIで送信します。メールの閲覧・変更は行いません。

業務週報

  • 所有者が指定したDriveの週報フォルダにある設定ファイルと対象週のファイルを読み取ります。
  • 生成した週報、バックアップおよび次週用の入力ファイルを同じ週報フォルダ内に作成・更新します。同期対象から削除されたアプリ管理ファイルはDriveのゴミ箱へ移動する場合があります。
  • Slackの指定チャンネルにある週報投稿を入力として使用します。この機能はGmailを使用しません。

国内株式決算情報収集

  • Drive上の明示された保有銘柄ファイル1件を読み取り、TDnetおよび企業公式サイトの公開情報と照合します。
  • 対象となる決算・IR資料のPDF、取得履歴および実行ログを、指定されたDriveフォルダに作成・更新します。保存済み資料を自動削除しません。
  • 新着資料のDriveリンク・公式URL、または重大な処理失敗の情報を、所有者が指定した宛先へGmail APIで送信します。メールの閲覧・変更は行いません。

OAuth権限の範囲

各機能は、その実行に必要なOAuth認証情報と権限だけを使用します。

  • ポートフォリオ月次レポートと業務週報は、本人が既に作成したDriveファイルを更新するため、OAuth権限上はDrive全体を読み書きできる権限を使用します。ただし、実装が処理するのは所有者が設定したフォルダID・ファイルIDと、その配下でアプリが管理するファイルだけです。
  • 国内株式決算情報収集は、アプリが作成・選択したファイルを管理する権限と、指定された保有銘柄ファイルを読み取る権限を使用します。
  • Gmailを使用する機能は送信専用権限だけを使用します。

情報の共有

Googleユーザーデータを販売せず、広告、第三者のマーケティング、信用評価には使用しません。自動処理にはGitHub Actionsを使用し、ポートフォリオ月次レポートのスケジュール管理と本人限定表示にはGoogle Apps Scriptを使用します。業務週報の入力取得にはSlackを使用します。Gmail通知は所有者が設定した宛先にだけ送信します。これらのサービスには、各処理、表示または通知に必要な最小限の情報だけを送信します。

保存と保護

生成したレポート、取得したPDF、処理履歴および一部の実行サマリーは、所有者本人のGoogle Driveに保存されます。自動処理中の一時ファイルはGitHub Actionsの一時実行環境で処理し、成果物としてアップロードせず、実行終了後に保持しません。Google OAuthの認証情報はGitHub Actionsの暗号化されたEnvironment Secretsで保護し、ソースコードや実行ログには記録しません。

保存期間と削除

Google Driveの成果物と実行ログは、所有者が削除するまで保持し、本人がDrive上で管理・削除できます。国内株式決算情報収集のDrive実行ログは、1年を目安に所有者が手動で削除します。GitHub Actionsの実行ログは各リポジトリの設定に従い原則90日以内保持され、所有者はGitHubのActions画面から期限前にも削除できます。認証情報や取得したファイル本文はActionsログへ記録しません。

データまたは実行ログの削除に関する依頼は、下記の連絡先で受け付けます。

アクセス権の解除

所有者は、Googleアカウントの「サードパーティ製のアプリとサービス」設定から、いつでも本アプリのアクセス権を確認・解除できます。解除後は、Googleデータを使用するワークフローが実行できなくなります。

Google API Services User Data Policyへの準拠

Google APIから受け取った情報の利用および他のアプリへの転送は、限定的な使用に関する要件を含むGoogle API Services User Data Policyに準拠します。
